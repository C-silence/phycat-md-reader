# theme-preview — 第一步：主题保真度预览

> 目标：在**浏览器里**直接查看 phycat 主题对真实 Markdown 的渲染效果，验证"复刻 Typora 观感"这一核心假设，并作为将来 Android WebView 阅读页的内容原型。

## 目录

```
theme-preview/
├── index.html              ← 预览页（双击即可打开，自包含示例文档）
├── sample.md               ← 样例文档（与 index.html 内嵌副本内容一致）
├── vendor/markdown-it.min.js  ← 已本地化（14.1.0），预览完全离线可用
└── README.md
```

## 怎么用

1. **双击 `index.html`**，用 Chrome / Edge 打开（无需联网、无需起服务）。
2. 顶栏操作：
   - **主题下拉 / ‹ ›**：在 9 套 phycat 主题间切换（8 亮 + Dark 暗色）。
   - **打开 md 文件…**：选一个你自己的 `.md`（或 `.markdown/.txt`）实时预览。
   - **恢复示例**：切回内置样例。
3. 主题文件与字体仍在上级目录原样引用（`../phycat-*.css` → `../phycat/` 字体），所以预览页**依赖父目录不被删除**。

## 侧边栏（左）

侧栏顶部是两个**导航页签**（不是上下堆叠），点谁显示谁：

- **📁 文件**：文件库。点「选择文件夹…」选一个目录后，会把其中**所有 `.md/.markdown`** 列成可折叠目录树，点任意文件即打开；顶栏「打开 md 文件…」可单独加入一个文件。当前打开的文件会高亮。
- **📐 结构**：当前文档的大纲（H1~H6 实时生成、按层级缩进）。点条目平滑跳到对应标题，滚动阅读时自动高亮所在章节。
- 侧栏底部固定一行「当前文档」名。整个侧栏用顶栏 **☰** 折叠/展开；**折叠状态与当前页签都会被记忆**（localStorage）。暗色主题下侧栏自动变深。

> ⚠️ 预览阶段的文件库是**内存版**（刷新页面需要重新选文件夹）。这个"文库 + 持久化"将在安卓阶段用 SAF 实现：记住文件夹授权、文件留在原处。

## 它为什么长这样（给第二步的说明）

- 阅读正文被包在 `<div id="write">` 中——这是 phycat 基础样式唯一认的正文容器（`max-width:950px`、居中、内边距、字色都由主题接管）。
- `index.html` 顶部工具条**不是主题的一部分**，纯粹为预览调试存在。Android 阶段会用 Compose 实现软件外壳，只把"阅读区"换成 WebView。
- 渲染流程 = markdown-it 出 HTML → **fidelity shim** 给标题补 `md-heading`、代码块补 `md-fences`、front-matter 转 `md-meta-block`、`- [ ]` 列表转 `task-list-item` + checkbox —— 这些类名是 Typora 主题能命中的关键。第二步 Android 侧需要沿用同样的 DOM 约定。
- 换肤即换 `<link>` 的 href（沿 `@import url(./phycat/phycat.*.css)` 链自动带上基础样式与字体），这就是"随时切换主题"在实现上的全部秘密。

## 已知局限（第一步范围外）

- 脚注、内联数学（`$..$`）、mermaid 图：当前按普通文本/代码处理，不加渲染。
- md 里的本地相对路径图片在浏览器 `file://` 下不解析（数据/网络图片可以）；Android 阶段再处理文件路径。
